# Clinic Patient Registration System

## Project description
Жүйе емхана пациенттерін тіркеуге және дәрігер қабылдауына жазылуды басқаруға арналған. 
Ол тіркеу бөлімінің жұмысын жеңілдетіп, қағаз журналдарды алмастырады. 
Жүйе пациенттердің деректерін, дәрігерлердің кестесін және жазылу тарихын сақтайды. 
Сондай-ақ қажетті ақпаратты жылдам табуға мүмкіндік береді.

## Users
- Тіркеу бөлімінің әкімшісі
- Дәрігер
- Пациент
- Жүйе әкімшісі

## Main functions
1. Жаңа пациентті тіркеу және оның карточкасын жүргізу.
2. Пациентті аты-жөні, ЖСН немесе телефон нөмірі бойынша іздеу.
3. Пациентті дәрігердің бос уақытына қабылдауға жазу.
4. Жазылуды болдырмау және басқа уақытқа ауыстыру.
5. Дәрігердің кестесін және күндізгі пациенттер тізімін қарау.
